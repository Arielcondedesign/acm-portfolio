# arielcnd.com

Portfolio personal de l'Ariel Conde, product designer.
Objectiu: web orientada a reclutadors i empreses amb propòsit (no captació de clients freelance, això es deriva a Regeneralia).

## Stack
- Astro estàtic
- Deploy a Hetzner (konsoleH)
- Idioma del lloc: anglès

## Project rules
- NO incloure referències a DENODL (pendent d'autorització).
- La captació de clients freelance es deriva a Regeneralia, no es fa en aquesta web.
- Imatges optimitzades i web lleugera: el missatge és low-carbon, ha de predicar amb l'exemple.
- Accessibilitat WCAG AA com a estàndard.

## Approach
- Think before acting. Read existing files before writing code.
- Be concise in output but thorough in reasoning.
- Prefer editing over rewriting whole files.
- Do not re-read files you have already read unless the file may have changed.
- Test your code before declaring done.
- No sycophantic openers or closing fluff.
- Keep solutions simple and direct.
- User instructions always override this file.
